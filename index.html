Tentang Saya

Mahasiswa S1 Teknik Informatika Universitas Pamulang (lulusan SMK Multimedia) yang berminat pada pengembangan aplikasi mobile Android. Menguasai Kotlin dan Android Studio, pengembangan web (Laravel, Next.js, Tailwind CSS), basis data (PostgreSQL, MySQL), serta perancangan sistem dengan UML dan metode Rapid Application Development (RAD).


Teliti, komunikatif, mampu bekerja dalam tim, dan cepat belajar. Mencari kesempatan sebagai Android Developer untuk menerapkan kemampuan pemrograman dan perancangan aplikasi.
